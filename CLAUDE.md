# Jerry – Press Release Pro

## Project Purpose
Jerry is an AI-powered press release assistant designed to help users create professional press releases quickly.

## Frontend
- Built with Base44
- React frontend
- Chat-style UI
- Animated typing indicators
- Press release library

## Backend
- Python Flask API
- Hosted on Render
- Endpoint:
  /chat

## Current API Behavior
POST /chat

Request:
{
  "message": "user text"
}

Response:
{
  "reply": "Jerry response"
}

## Branding
- Name: Jerry
- Product: Press Release Pro
- Tone: Professional, warm, intelligent, business-focused
